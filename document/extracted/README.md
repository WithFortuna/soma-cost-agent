# 첨부파일 텍스트 추출본

이 폴더는 `document/assets/`의 첨부파일을 문서 기반 질의응답에 쓰기 쉽도록 텍스트화한 결과입니다.

- `assets/*.txt`: 각 첨부파일별 추출 텍스트 또는 이미지 설명
- `index.json`: 원본 파일, 추출 파일, 해시, 중복 여부, 추출 방식 인덱스
- `image_descriptions.json`: 이미지 파일에 대한 수동 설명 및 핵심 텍스트 전사

## 추출 기준

- DOCX: 문단과 표 셀 텍스트를 추출했습니다.
- XLSX: 시트별 셀 값을 추출했습니다.
- PDF: 페이지별 텍스트를 추출했습니다.
- 이미지: 자동 OCR 대신, 문서 기반 답변에 필요한 대표 이미지 표/화면을 시각 확인 후 설명 또는 전사했습니다.

## 주의

이미지의 세부 픽셀 텍스트까지 완전 OCR한 결과는 아닙니다. 일정표와 지원항목표처럼 답변에 중요한 이미지는 핵심 내용을 전사했지만, 불확실한 경우 원본 이미지와 Markdown 문서를 함께 확인해야 합니다.
