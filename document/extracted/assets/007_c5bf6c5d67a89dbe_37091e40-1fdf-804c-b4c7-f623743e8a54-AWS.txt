Ⅰ. MFA 소개
◆ MFA (Multi-Factor Authentication)
AWS Multi-Factor Authentication(MFA)은 사용자 이름과 암호 외에 보안을 한층 더 강화할 수 있는 간단하며 효과적인 수단입니다. 
AWS 계정에 대한 보안 영역은 사용자의 책임으로, 해킹 등 사고 발생 시 AWS와 파트너는 책임을 대신하지 않습니다. MFA는 해킹을 방지하기 위한 2차 보안 인증 
서비스이자 최소한의 안전장치로써, MFA를 활성화하면 사용자가 AWS 웹 사이트에 로그인할 때 사용자 이름과 암호 뿐 아니라 AWS MFA 디바이스의 6자리 인증
코드를 입력하는 메시지가 표시됩니다. 계정에 대한 보안 강화는 선택이 아닌 필수입니다.
❖ 참고 문서 #.1 : AWS에서 Multi-Factor Authentication(MFA) 사용하기 : https://docs.aws.amazon.com/ko_kr/IAM/latest/UserGuide/id_credentials_mfa.html
❖ 참고 문서 #.2 : AWS에서 Virtual Multi-Factor Authentication(MFA) 디바이스 활성화 : https://docs.aws.amazon.com/ko_kr/IAM/latest/UserGuide/id_credentials_mfa_enable_virtual.html  
◆ 가상 애플리케이션을 이용한 MFA
스마트폰 애플리케이션을 이용하여 MFA를 사용할 수 있습니다.
아래 MFA App을 무료로 스마트폰에 다운로드 / 설치하여 AWS 계정에 대한 보안을 강화하십시오.
❖ 사용할 수 있는 가상 MFA App
A. Authy
B. Duo Mobile
C. LastPass Authenticator
D. Microsoft Authenticator
E. Google Authenticator
❖ 참고 문서 : https://aws.amazon.com/ko/iam/features/mfa/?audit=2019q1

Ⅱ. AWS 공동 책임 모델
◆ AWS 책임 : '클라우드의 보안’ 
AWS는 AWS 클라우드에서 제공되는 모든 서비스를 실행하는 인프라를 
보호할 책임이 있습니다. 이 인프라는 AWS 클라우드 서비스를 실행하는 
하드웨어, 소프트웨어, 네트워킹 및 시설로 구성됩니다.
❖ 출처 : https://aws.amazon.com/ko/compliance/shared -responsibility-model/
◆ 고객 책임 : '클라우드에서의 보안’ 
고객은 데이터 관리(암호화 옵션 포함), 자산 분류, 적절한 허가를 부여하는 
IAM 도구 사용에 책임이 있습니다.
AWS Multi-Factor Authentication(MFA)은 사용자 이름과 암호 외에 
보안을 한층 더 강화할 수 있는 간단하며 효과적인 수단입니다. 
◆ 고객 / AWS 공동 책임 모델은 IT 제어까지도 확장됩니다. 
IT 환경을 운영할 책임이 AWS와 고객 간에 분담되는 것과 마찬가지로 IT 제어의 관리, 운영 및 검증도 분담됩니다. AWS는 AWS 환경에서 
배포되는 물리적 인프라와 관련하여 이전에는 고객이 관리해야 했던 제어 항목을 대신 관리함으로써 고객이 제어를 운영하는 부담을 경감하도록 
도울 수 있습니다. 고객은 제공되는 AWS 제어 및 규정 준수 설명서를 사용하여 필요에 따라 제어 평가 및 확인 절차를 수행할 수 있습니다.
